6. Tecnologías

Parte del proyecto Tecnología ¿Para qué la usamos?
Interfaz HTML5, CSS y JavaScript Estructura, estilos y funciones de las páginas
Programación del servidor (backend) PHP 8 Registro e inicio de sesión, referidos, puntos, canjes y las validaciones de cada proceso
Diseño responsivo Bootstrap 5 y media queries Adaptar la página a teléfono, tableta y computadora
Base de datos MySQL Guardar socios, referidos, puntos y recompensas
Servidor local MAMP (Apache) Probar la plataforma en nuestras computadoras
Seguridad HTTPS y contraseñas cifradas (bcrypt) Proteger los datos de los socios
Control de versiones Git y GitHub Trabajar en equipo y guardar el historial
Editor Visual Studio Code Escribir el código
Diseño de prototipos Figma Diseñar y mostrar las pantallas en teléfono, tableta y computadora

¿Por qué estas?

  • MAMP ya incluye Apache y MySQL, así que se puede empezar sin instalar más.
  • Bootstrap y Figma ayudan a que la plataforma sea responsiva.
  • Todas son gratuitas y tienen mucha documentación en español.

4. Requisitos No Funcionales

Código Categoría Descripción
RNF01 Seguridad Las contraseñas deben almacenarse cifradas y toda la comunicación debe realizarse mediante HTTPS.
RNF02 Seguridad Cada usuario solo debe acceder a las funciones de su rol (Socio, Administrador o Gestor de contenidos).
RNF03 Seguridad Los datos de socios y referidos deben tratarse conforme a la Ley Orgánica de Protección de Datos Personales del Ecuador.
RNF04 Usabilidad Las acciones principales (registrar un referido, inscribirse en una actividad, consultar puntos) deben realizarse en máximo 3 clics desde el inicio.
RNF05 Accesibilidad La aplicación debe cumplir las pautas WCAG 2.1 nivel AA (contraste suficiente, texto alternativo en imágenes y navegación por teclado).
RNF06 Rendimiento Las páginas principales deben cargar en menos de 3 segundos.
RNF07 Compatibilidad La aplicación debe funcionar en las versiones actuales de Chrome, Firefox, Edge y Safari, y adaptarse a teléfonos, tabletas y computadoras.
RNF08 Disponibilidad La aplicación debe estar disponible al menos el 99 % del tiempo, con copias de seguridad diarias de la base de datos.
RNF09 Diseño responsivo La interfaz debe adaptarse al ancho de pantalla de teléfonos, tabletas y computadoras, sin desplazamiento horizontal.
RNF10 Mantenibilidad El código debe estar organizado, comentado y guardado en un repositorio con control de versiones.
RNF11 Escalabilidad El sistema debe poder crecer en número de socios sin rehacer su diseño.
RNF12 Auditoría Se deben registrar las acciones importantes, como los cambios de estado de los referidos y los canjes de recompensas.
RNF13 Idioma La interfaz debe estar en español y las fechas deben mostrarse como día/mes/año.
